2. Deskripsi Project

Sistem Parking adalah aplikasi berbasis web yang digunakan untuk membantu proses pengelolaan parkir secara digital.

Sistem ini menyediakan fitur pengelolaan pengguna, kendaraan, area parkir, booking, tarif, transaksi, log aktivitas, dan laporan.

Aplikasi memiliki beberapa jenis pengguna yaitu Admin, Owner, Petugas, dan Pengguna/Pelanggan. Setiap pengguna memiliki hak akses yang berbeda sesuai dengan role masing-masing.

3. Tujuan Project

  1. Membantu pengelolaan data kendaraan secara digital.
  2. Memudahkan pengguna melakukan booking tempat parkir.
  3. Menampilkan informasi ketersediaan area parkir.
  4. Membantu petugas dalam proses operasional parkir.
  5. Memudahkan admin mengelola data sistem.
  6. Membantu owner melihat laporan sistem.
  7. Menyimpan data transaksi secara terstruktur.
  8. Meningkatkan efisiensi pengelolaan parkir.

7. Sistem Login dan Hak Akses

Sistem menggunakan PHP Session untuk menjaga status login pengguna. 

<?php

session_start();

if (!isset($_SESSION['id_user'])) {
    header("Location: login.php");
    exit;
}

Sistem juga membatasi akses berdasarkan role. 

if ($_SESSION['role'] != "admin") {
    die("Akses ditolak!");
}

9. Proses Booking Parkir

  1. Pengguna login ke sistem.
  2. Pengguna membuka menu cek area.
  3. Sistem menampilkan area parkir.
  4. Pengguna memilih kendaraan.
  5. Pengguna melakukan pemesanan tempat.
  6. Sistem menyimpan data booking.
  7. Pengguna melakukan konfirmasi ketika sudah berada di lokasi.
  8. Petugas memproses kendaraan.
  9. Data transaksi disimpan ke database.
  10. Pengguna dapat melihat kuitansi dan riwayat.

12. Keamanan Sistem

  • Menggunakan session untuk autentikasi pengguna.
  • Menggunakan password_hash() untuk password.
  • Menggunakan password_verify() saat login.
  • Membatasi halaman berdasarkan role.
  • Melakukan validasi input pengguna.
  • Menggunakan prepared statement.
  • Tidak membagikan password database.
  • Tidak menampilkan error database pada production.

13. Menjalankan Sistem Secara Lokal

  1. Jalankan Apache pada XAMPP.
  2. Jalankan MySQL pada XAMPP.
  3. Letakkan project pada folder:
C:\xampp\htdocs\parking
  1. Import database melalui phpMyAdmin.
  2. Sesuaikan konfigurasi database pada db.php.
  3. Buka browser.
  4. Akses alamat:
http://localhost/parking/

14. Deployment ke InfinityFree

  1. Membuat akun InfinityFree.
  2. Membuat domain atau subdomain.
  3. Membuat database MySQL.
  4. Membuka phpMyAdmin.
  5. Import database project.
  6. Upload file project ke folder htdocs.
  7. Mengubah konfigurasi database pada db.php.
  8. Memastikan seluruh file telah ter-upload.
  9. Membuka domain website.

18. Kesimpulan

Sistem Parking merupakan aplikasi berbasis web yang dirancang untuk membantu proses pengelolaan tempat parkir secara digital.

Dengan adanya pembagian hak akses Admin, Owner, Petugas, dan Pengguna, setiap pengguna dapat menjalankan fungsi sesuai dengan kebutuhan dan hak akses masing-masing.

Sistem dapat membantu mengelola data kendaraan, area parkir, booking, tarif, transaksi, pengguna, serta laporan secara lebih terstruktur.

Dengan pengembangan fitur tambahan seperti pembayaran online, QR Code, notifikasi, dan monitoring slot secara real-time, Sistem Parking dapat dikembangkan menjadi aplikasi pengelolaan parkir yang lebih lengkap dan modern.
